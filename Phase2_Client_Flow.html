What we are building

Two features, one dashboard

Both features live in the same Central Dashboard and work together: whatever a user is allowed to see also applies to GBP calls.

🔐
Requirement 1

Role-Based Access (RBAC)

Clients and team members log in with their own account and see only the features and clients their role allows.

  • Admin invites users and picks their role and clients
  • Roles & Permissions screen to create custom roles
  • Sidebar, pages and buttons follow the user's permissions
  • Client users only ever see their own client's data
📍
Requirement 2

Google Business Profile (GBP) Calls

Calls from each client's Google Business Profile listing are tracked next to the existing LSA and SEM calls.

  • GBP calls pulled from GoHighLevel (eMConnect)
  • Same AI analysis: booking status, summary, transcript
  • GBP source filter and KPI cards on the dashboard
  • GBP included in the Excel export

Built-in safeguards

Safe by default

🧱

Client data isolation

Non-admin users only get data for the clients assigned to them, on every page, KPI, export and notification.

🛰️

Checked on the server

Hidden buttons are also blocked in the API, so direct links or API calls return "Access denied".

⚡

Changes apply immediately

When Admin changes a role or removes a user, that user's session is refreshed or signed out.

🔒

No lock-out

The default Admin account can't be removed or demoted, and there is always at least one Admin.

📜

Activity log

Logins, booking-status edits, exports and team changes are recorded with who did them.

✉️

Invite-only accounts

Only invited email addresses can create an account. Invites expire and can be resent.
