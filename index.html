What we are building

Three features, one dashboard

All three live in the same Central Dashboard: login access for deep work, GBP as a third call source, and a view-only embed URL for white-label reports.

🔐
Requirement 1

Role-Based Access (RBAC)

Clients and team members log in with their own account and see only the features and clients their role allows.

  • Admin invites users and picks their role and clients
  • Roles & Permissions screen to create custom roles
  • Sidebar, pages and buttons follow the user's permissions
  • Client users see only permitted dashboards and their own client's data
📍
Requirement 2

Google Business Profile (GBP) Calls

Calls from each client's Google Business Profile listing are tracked next to the existing LSA and SEM calls.

  • GBP calls pulled from GoHighLevel (eMConnect)
  • eMConnect “Local SEO” treated as GBP
  • GBP source filter and KPI cards on the dashboard
  • GBP included in the Excel export
🔗
Requirement 3

Embeddable view-only URL

A client-scoped link Admin can paste into Explore Media’s white-label reporting platform (or Slides). No extra login.

  • Generate from Clients → Embed link
  • Shows KPIs, charts and client name
  • Date range is the only interactive control
  • Optional expiry; revoke anytime

Built-in safeguards

Safe by default

🧱

Client data isolation

Non-admin users only get data for the clients assigned to them, on every page, KPI, export and notification.

🛰️

Checked on the server

Hidden buttons are also blocked in the API, so direct links or API calls return "Access denied".

⚡

Changes apply immediately

When Admin changes a role or removes a user, that user's session is refreshed or signed out.

🔒

No lock-out

The default Admin account can't be removed or demoted, and there is always at least one Admin.

📜

Activity log

Logins, booking-status edits, exports and team changes are recorded with who did them.

✉️

Invite-only accounts

Only invited email addresses can create an account. Invites expire and can be resent.

Requirement 3 · Embed links

A URL for white-label reports

Some clients only need the KPI view inside Explore Media’s reporting platform. They should not need a Call Analyzer login or tab-switching.

📎

Paste a URL

Same pattern as Data Studio or Accelerant: Admin copies a client link into the white-label widget (URL preferred over iframe).

👁️

View-only KPIs

Shows client name, performance cards and charts. No transcripts, lead table, or team settings.

🧭

Two access paths

Embed for report viewers. RBAC login when they need recordings, reanalyze, or exports.

Portable One client URL works in the white-label portal, Google Slides, or any tool that accepts a link. It updates when the dashboard data updates.
Clients → Actions

One Embed link button per client

Always labelled Embed link. It opens the same modal every time. A green dot means that client already has an active share link.
